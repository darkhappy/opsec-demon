# MPRIS liaison

Fictional filing authority: NIGHTFALL / ABYSS-999.

On Linux, the music line reads playerctl metadata from a compatible MPRIS player. `music status` reports state and `music live` restores local telemetry.

If no compatible player is active, the deck reports that state. `music demo` deliberately substitutes a demo track.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
