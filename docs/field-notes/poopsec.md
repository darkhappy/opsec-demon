# Porcelain archdemon protocol

Fictional filing authority: NIGHTFALL / ABYSS-999.

`poopsec on` and `poopsec off` control the sewer-lore persona. Ctrl-B toggles it; `--poopsec` selects it at startup.

The name is deliberate comic roleplay. It confers no operational security guarantees.
