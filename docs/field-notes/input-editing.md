# Cursor discipline

Fictional filing authority: NIGHTFALL / ABYSS-999.

Left/Right, Home/End, and Ctrl-A/Ctrl-E move the cursor. Backspace deletes; Ctrl-U clears the input. Input is limited to 4,096 bytes.

PgUp/PgDn scroll the transcript. Commands continue to have real effects while animations run.
