# Nightwraith identity bureau

Fictional filing authority: NIGHTFALL / ABYSS-999.

`callsign NIGHTWRAITH` sets the session persona. Callsigns accept up to 24 ASCII letters, digits, underscores, and hyphens.

The name is fictional session identity. It does not change OS identity, permissions, or network attribution.
