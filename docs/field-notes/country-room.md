# Archipelago command council

Fictional filing authority: NIGHTFALL / ABYSS-999.

`hoi4 list` opens the fictional country selector. `hoi4 select PHI` selects the Philippines, the initial choice.

GER, SOV, USA, ENG, FRA, ITA, JAP, POL, CHI, and PHI are supported. UK and USSR are aliases.
