# Phantom arcade controller

Fictional filing authority: NIGHTFALL / ABYSS-999.

`sdvx play` enables Q/E and U/O knob keys, A/S/D/F BT buttons, and J/K FX buttons. Enter or backtick returns to command input.

Hits earn fictional criticals and points. There is no timing judgment or connection to a rhythm-game client.
