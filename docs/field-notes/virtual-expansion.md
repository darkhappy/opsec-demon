# VULCAN soul bank

Fictional filing authority: NIGHTFALL / ABYSS-999.

`expansion expand` enables 512 virtual GB; `expansion allocate 128` and `expansion release 64` update bookkeeping.

Whole-number requests enforce capacity. No actual RAM is allocated and no MCP server is changed.
