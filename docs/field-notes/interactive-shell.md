# Native shell handoff

Fictional filing authority: NIGHTFALL / ABYSS-999.

Use `shell` for your native interactive shell, or `shell bash` and `shell zsh` for an explicit choice. `shell vim file.txt` and `shell ssh user@host` hand terminal interaction to those programs.

After the program exits, Enter returns to the deck. Native shell startup configuration belongs to that shell.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
