# Igloo object archive

Fictional filing authority: NIGHTFALL / ABYSS-999.

`bucket put igloo.txt "dance floor online"`, `bucket get igloo.txt`, and `bucket ls` use session-only memory. `bucket sync` narrates a fake relay.

Limits are 100 objects, 4,096 bytes per object, and 128-character printable names without slashes or traversal. This is not cloud storage.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
