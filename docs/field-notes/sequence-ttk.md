# Finite shot sequence audit

Fictional filing authority: NIGHTFALL / ABYSS-999.

Use calculation sequence-body or sequence-head to evaluate an ordered shot list. Numeric swap_ms supplies an assumed switch duration; otherwise timing is firing-only.

The model stops at a killing shot and does not repeat the sequence. Results are idealized estimates, not verified live-game breakpoints.
