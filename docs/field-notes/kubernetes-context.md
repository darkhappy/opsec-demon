# Local context placard

Fictional filing authority: NIGHTFALL / ABYSS-999.

The footer reads `kubectl config current-context`, honoring KUBECONFIG. Missing or unavailable context is displayed as a dash.

This helper reads local configuration and makes no cluster request. Starship's own Kubernetes module is configured independently.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
