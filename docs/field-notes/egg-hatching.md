# Two-second hatch channel

Fictional filing authority: NIGHTFALL / ABYSS-999.

`egg hatch` starts a nonblocking two-second channel, pays out, and removes carrying stats. `--egg` starts carrying at launch.

Carrying stats and permanent session buffs affect only this simulator. No real match state is modified.
