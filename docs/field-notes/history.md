# Session memory archive

Fictional filing authority: NIGHTFALL / ABYSS-999.

Up and Down recall commands. `history` shows the in-memory log, capped at 1,000 commands. A leading space excludes a command from this history.

The application does not save its own history to disk. Child programs may save data under their own policies.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
