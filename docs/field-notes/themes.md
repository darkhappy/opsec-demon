# Venom color authorization

Fictional filing authority: NIGHTFALL / ABYSS-999.

Use `theme crimson`, `theme ghost`, or `theme venom`. `--plain` and `NO_COLOR=1` remove color while the TUI still uses cursor-control sequences.

Colors use ANSI 256-color indices. A color palette is an aesthetic choice, not cryptographic camouflage.
