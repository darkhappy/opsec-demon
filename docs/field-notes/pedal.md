# Fictional stomp authorization

Fictional filing authority: NIGHTFALL / ABYSS-999.

`pedal stomp`, `pedal release`, and `pedal status` manage the fictional effects pedal. Ctrl-G stomps it and adds 15 to the larp meter up to 999.

Release raises the pedal without resetting the meter. There is no hardware pedal control.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
