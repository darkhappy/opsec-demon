# Glyph procurement

Fictional filing authority: NIGHTFALL / ABYSS-999.

`mise run font` installs a verified JetBrainsMono Nerd Font Mono archive. Select the font in your terminal settings, then use `--nerd-font` or `icons on`.

Plain ASCII works without the font. The installer does not change the terminal's selected font.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
