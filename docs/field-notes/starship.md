# Prompt liaison

Fictional filing authority: NIGHTFALL / ABYSS-999.

The deck invokes installed Starship with the current directory, previous status, and terminal width. Use `mise exec --` to include the pinned binary on PATH.

Prompt output is flattened and ANSI escapes removed. Without Starship, the footer falls back to directory and local Git branch.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
