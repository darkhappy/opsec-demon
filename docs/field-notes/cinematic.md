# Fifteen seconds to imaginary clearance

Fictional filing authority: NIGHTFALL / ABYSS-999.

The default interactive boot takes fifteen seconds. Ctrl-D aborts; `--instant` and `--no-banner` skip it. `cinematic` replays the sequence.

Boot command narration is marked SIM. Completion establishes a local worker echo, rings the terminal bell, and asks you to say I'M IN.

See the [full operating manual](../../README.md) and [actual security boundaries](../../SECURITY.md).
