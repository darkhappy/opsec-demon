# Real boundaries behind the theatrical clearance stamp

OPSEC DEMON executes real commands through `/bin/sh` with your permissions. The visual
shell is not a sandbox, anonymity tool, encryption layer, or credential manager.
`mainframe connect` opens real plain TCP; local simulator traffic stays in-process.

Do not put credentials in issues, terminal recordings, or committed environment files.
Ignored files can still be added with force; already tracked files remain tracked.
The random API-shaped `.gitignore` comment is not consumed by this application or
associated with an account. No API key is required to launch the shell.

For a suspected vulnerability, provide a minimal reproduction without secrets. If this
repository's GitHub Security tab offers private reporting, use it; otherwise use the
maintainer's available private contact channel. No private reporting service or response
SLA is currently configured by this repository.
